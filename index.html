Blizzard Battle.net API Einstellungen

Offizielle Equipment-Abfrage (`profile/wow/character/.../equipment`)

So erhältst du deine kostenlosen Blizzard API Zugangsdaten:

  1. Öffne develop.battle.net/access/clients und logge dich ein.
  2. Klicke auf "Create Client" (Name beliebig, Redirect URL z.B. http://localhost).
  3. Kopiere deine Client ID und dein Client Secret hier hinein.

Tipp: Falls du gerade keinen API-Key zur Hand hast, kannst du beim Charakter-Import jederzeit den Raider.IO Direkt-Import (ohne API-Key) nutzen!
